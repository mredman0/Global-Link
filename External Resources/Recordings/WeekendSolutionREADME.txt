
ChromaSphere weekend solution X post PROCESS:
----------------------------------------------

1. Open ChromaSphere on iPhone, must have been built with ENABLE_MARKETING_TOOLSET compiler flag
2. Open daily puzzles page, load puzzles of desired date
3. Open the first grandmaster puzzle
4. Press the unlabeled button which will instantly solve the puzzle and start the smooth rotation
5. Record a clip of at least 8 seconds
6. Upload clip to drive
7. Download clip to computer, open it in CapCut
8. Set aspect ratio of clip and of output to 1:1
9. Set clip speed to 0.2x
10. Trim clip end to exactly 40 seconds
11. Export to gif
12. Run MakeGif50FPS.py on new gif
13. Schedule a new X post using the below TEMPLATE and the new gif as the media. Be sure to change the date in the post text
